# Decision Tradeoff Agent

This agent helps users make better decisions by analyzing tradeoffs between options.

## Features
- Takes user decision input
- Asks for priority (salary, interest, stability)
- Uses LPI tools:
  - query_knowledge
  - get_insights
- Provides structured tradeoff analysis
- Cites sources

## How to Run
1. Start LPI sandbox
2. Run:
   python agent.py


## Example
Input: AI vs Web Development  
Output: Tradeoff analysis + recommendation
